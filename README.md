# Clone Disney+ Interface

Repositório do projeto **Clone Disney+**, uma replicação do layout e navegação da plataforma de streaming Disney+.  
O foco é reproduzir a experiência visual da homepage, destaques, carrosséis e seções de conteúdo, para fins de estudo e prática de front‑end.

---

## Objetivo

- Reproduzir a interface principal do Disney+ (header, destaques em destaque, carrosséis de filmes/séries, rodapé, etc.).
- Treinar desenvolvimento de interfaces responsivas e ui beem estruturadas.
- Aplicar boas práticas de HTML, CSS e JavaScript.


## 🛠 Tecnologias utilizadas

- Linguagem de marcação: `HTML5`
- Estilização: `SCSS`
-  Programação: `JavaScript`

---

## Instalação e execução

1. Clone o repositório:
   ```bash
   git clone https://github.com/Rodrigo-GitHb/clone_disneyplus.git
   cd clone_disneyplus
   ```

2. Abra o projeto no navegador:
   - Abra o arquivo `index.html` diretamente no navegador, ou
   - Use um servidor simples de desenvolvimento (ex: `live-server`):
     ```bash
     npm install -g live-server
     live-server
     ```

## Funcionalidades implementadas

- Header com logo, menu e ícones de perfil.
- Hero section com imagem em destaque e botões de ação.
- Carrosséis com filmes/séries organizados por categorias (ex.: “Mais populares”, “Marvel”, “Star Wars”, etc.).
- Rodapé com links de navegação e informações institucionais.
- Layout responsivo (mobile, tablet e desktop).
